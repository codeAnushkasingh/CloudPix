Enterprise Security Flow

How CloudPix Keeps Images Secure

Designed from day one to safeguard your assets with zero credential exposure and time-limited access.

01

Frontend Upload

The browser validates file size (≤ 5 MB) and format (JPG, PNG, WEBP), then streams the binary to the Python Flask backend. No AWS keys are stored on the client.

02

IAM Role & Boto3

On AWS EC2, Boto3 automatically retrieves temporary session credentials from the EC2 Instance Metadata Service (IMDS). Bucket is kept 100% private.

03

Presigned URL Minting

When an image is requested, Boto3 cryptographically signs a time-limited GET URL valid for 60 minutes. Direct public bucket access remains completely blocked.

04

Local Demo Mode

Running without AWS credentials? CloudPix auto-detects this and runs a standalone local demo store. The UI clearly labels all images as demo assets.

Zero Frontend Leaks

🚀

Full-Stack Autonomy

Flask simultaneously serves the REST API and the responsive vanilla frontend with zero node dependencies.
